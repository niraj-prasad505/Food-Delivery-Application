# Food Delivery Application

A full-stack food delivery web application developed as an **internship project** using the **MERN Stack**.

 **Status: Under Development**

## Tech Stack

* **MongoDB** — Database
* **Express.js** — Backend framework
* **React.js** — Frontend
* **Node.js** — Runtime environment
* **Tailwind CSS** — UI styling
