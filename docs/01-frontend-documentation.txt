FRONTEND DOCUMENTATION — FOOD DELIVERY MVP

Goal:
Build a simple, fully working food-delivery project within 10–15 days.
Use a clean and practical structure, but avoid advanced architecture and unnecessary features.

==================================================
1. REQUIRED CUSTOMER PAGES
==================================================

1. Home / Landing
   - Banner / Ads
   - Featured Products
   - Popular Products
   - Shop highlights
   - Navbar + Footer

2. Login
   - Customer login

3. Registration
   - Customer registration

4. Shop Listing
   - Show available shops

5. Shop Details
   - Shop information
   - Shop products

6. Product Listing
   - Show products

   - Image
   - Name
   - Price
   - Description
   - Quantity
   - Add to Cart
   - Add / Remove Wishlist

   - Products
   - Quantity
   - Price
   - Total

   - Show saved products

    - Delivery address

    - Total
    - Payment method
    - Place Order

    - Order confirmation

    - Customer's orders
    - Order status

    - Products

==================================================
3. SHARED REUSABLE COMPONENTS
==================================================

Keep components simple and reusable.

- Navbar
- Footer
- ProductCard
- ShopCard
- Button
- Input
- Loading
- ErrorMessage
- EmptyState
- QuantityControl
- ProtectedRoute

Rule:
Create a component when it is reused or makes a page cleaner.
Do not create unnecessary components.
