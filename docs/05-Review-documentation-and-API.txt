# REVIEW MODULE

## Architecture → API → Postman → Frontend

---

# 1. PURPOSE

The Review module allows customers to:

* Review a Shop
* Review a Product
* View Shop reviews
* View Product reviews
* Update their own review
* Delete their own review

The Review module is independent from the existing authentication
architecture.

Existing User authentication is reused only to identify the logged-in
customer.

# 4. REVIEW DATABASE STRUCTURE

## Review-model.js

```js
const mongoose = require("mongoose");

const reviewSchema = new mongoose.Schema(
  {
    user: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "User",
      required: true,
    },

    shop: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "Shop",
      required: true,
      index: true,
    },

    product: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "Product",
      default: null,
      index: true,
    },

    rating: {
      type: Number,
      required: true,
      min: 1,
      max: 5,
    },

    comment: {
      type: String,
      trim: true,
      maxlength: 500,
      default: null,
    },
  },
  {
    timestamps: true,
  }
);

reviewSchema.index(
  { user: 1, product: 1 },
  {
    unique: true,
    partialFilterExpression: {
      product: { $exists: true },
    },
  }
);

module.exports = mongoose.model("Review", reviewSchema);
```

# 5. HOW THE DATA WORKS

## Shop Review

A customer reviews the shop itself.

```text
User
  |
  v
Review
  |
  +---- shop
  |
  +---- product = null
  |
  +---- rating
  |
  +---- comment
```

Example:

```json
{
  "shop": "68a123456789",
  "rating": 4,
  "comment": "Good food and fast delivery."
}
```

The `user` is NOT sent from Postman/frontend.

The backend gets it from:

```js
req.user.id
```

---

# 6. PRODUCT REVIEW

A customer reviews a specific product.

```text
User
  |
  v
Review
  |
  +---- shop
  |
  +---- product
  |
  +---- rating
  |
  +---- comment
```

Example:

```json
{
  "shop": "68a123456789",
  "product": "68b987654321",
  "rating": 5,
  "comment": "Very tasty!"
}
```

The backend must verify:

```text
Product belongs to Shop
```

For example:

```text
Product A
   |
   v
Shop A
```

Valid:

```text
Product A + Shop A
```

Invalid:

```text
Product A + Shop B
```

| Method | Endpoint                          | Authentication | Purpose             |
| ------ | --------------------------------- | -------------- | ------------------- |

# 9. REVIEW ROUTES CODE

## reviewRoutes.js

```js
const express = require("express");

const {
  createReview,
  getShopReviews,
  getProductReviews,
  updateReview,
  deleteReview,
} = require("../controllers/reviewController");

const authMiddleware = require("../middleware/authMiddleware");

const router = express.Router();


// Create review
router.post("/", authMiddleware, createReview);


// Get shop reviews
router.get("/shop/:shopId", getShopReviews);


// Get product reviews
router.get("/product/:productId", getProductReviews);


// Update own review
router.put("/:reviewId", authMiddleware, updateReview);


// Delete own review
router.delete("/:reviewId", authMiddleware, deleteReview);


module.exports = router;
```

# 11. REVIEW CONTROLLER

## reviewController.js

```js
const Review = require("../models/Review-model");
const Product = require("../models/Product-model");
const Shop = require("../models/Shop-model");


// ============================================================
// CREATE REVIEW
// ============================================================

const createReview = async (req, res) => {
  try {
    const { shop, product, rating, comment } = req.body;

    // Validate required fields
    if (!shop || rating === undefined) {
      return res.status(400).json({
        message: "Shop and rating are required",
      });
    }

    // Validate rating
    if (rating < 1 || rating > 5) {
      return res.status(400).json({
        message: "Rating must be between 1 and 5",
      });
    }

    // Check shop
    const shopExists = await Shop.findById(shop);

    if (!shopExists) {
      return res.status(404).json({
        message: "Shop not found",
      });
    }

    // Check product if provided
    if (product) {
      const productExists = await Product.findOne({
        _id: product,
        shop: shop,
      });

      if (!productExists) {
        return res.status(404).json({
          message: "Product not found in this shop",
        });
      }
    }

    // Create review
    const review = await Review.create({
      user: req.user.id,
      shop,
      product: product || null,
      rating,
      comment: comment || null,
    });

    return res.status(201).json({
      message: "Review created successfully",
      review,
    });

  } catch (error) {

    // Duplicate product review
    if (error.code === 11000) {
      return res.status(409).json({
        message: "You have already reviewed this product",
      });
    }

    console.error("Create review error:", error);

    return res.status(500).json({
      message: "Server error",
    });
  }
};


// ============================================================
// GET SHOP REVIEWS
// ============================================================

const getShopReviews = async (req, res) => {
  try {
    const { shopId } = req.params;

    const reviews = await Review.find({
      shop: shopId,
    })
      .populate("user", "name")
      .populate("product", "name")
      .sort({ createdAt: -1 });

    return res.status(200).json({
      count: reviews.length,
      reviews,
    });

  } catch (error) {

    console.error("Get shop reviews error:", error);

    return res.status(500).json({
      message: "Server error",
    });
  }
};


// ============================================================
// GET PRODUCT REVIEWS
// ============================================================

const getProductReviews = async (req, res) => {
  try {
    const { productId } = req.params;

    const reviews = await Review.find({
      product: productId,
    })
      .populate("user", "name")
      .sort({ createdAt: -1 });

    return res.status(200).json({
      count: reviews.length,
      reviews,
    });

  } catch (error) {

    console.error("Get product reviews error:", error);

    return res.status(500).json({
      message: "Server error",
    });
  }
};


// ============================================================
// UPDATE REVIEW
// ============================================================

const updateReview = async (req, res) => {
  try {
    const { reviewId } = req.params;
    const { rating, comment } = req.body;

    const review = await Review.findOne({
      _id: reviewId,
      user: req.user.id,
    });

    if (!review) {
      return res.status(404).json({
        message: "Review not found",
      });
    }

    // Validate rating
    if (rating !== undefined) {
      if (rating < 1 || rating > 5) {
        return res.status(400).json({
          message: "Rating must be between 1 and 5",
        });
      }

      review.rating = rating;
    }

    // Update comment
    if (comment !== undefined) {
      review.comment = comment;
    }

    await review.save();

    return res.status(200).json({
      message: "Review updated successfully",
      review,
    });

  } catch (error) {

    console.error("Update review error:", error);

    return res.status(500).json({
      message: "Server error",
    });
  }
};


// ============================================================
// DELETE REVIEW
// ============================================================

const deleteReview = async (req, res) => {
  try {
    const { reviewId } = req.params;

    const review = await Review.findOneAndDelete({
      _id: reviewId,
      user: req.user.id,
    });

    if (!review) {
      return res.status(404).json({
        message: "Review not found",
      });
    }

    return res.status(200).json({
      message: "Review deleted successfully",
    });

  } catch (error) {

    console.error("Delete review error:", error);

    return res.status(500).json({
      message: "Server error",
    });
  }
};


module.exports = {
  createReview,
  getShopReviews,
  getProductReviews,
  updateReview,
  deleteReview,
};
```

# 29. AUTHENTICATION FLOW

The frontend stores the JWT according to the project's existing
authentication implementation.

When creating, updating, or deleting a review:

```text
Frontend
   |
   | Authorization: Bearer JWT
   v
authMiddleware
   |
   | verifies token
   v
req.user.id
   |
   v
reviewController
```

The Review controller should never trust:

```json
{
  "user": "some-user-id"
}
```

from the frontend.

Instead:

```js
user: req.user.id
```

must be used.

---

# 30. REVIEW OWNERSHIP

Suppose User A creates:

```text
Review A
   |
   +---- user = User A
```

User B cannot modify it.

The controller checks:

```js
const review = await Review.findOne({
  _id: reviewId,
  user: req.user.id,
});
```

Therefore:

```text
User A -> Update Review A ✅
User B -> Update Review A ❌
```

The same rule applies to deletion.

---

# 31. RATING ARCHITECTURE

Reviews remain the source of truth.

Example:

```text
Product A

Review 1 = 5
Review 2 = 4
Review 3 = 5
```

Average:

```text
(5 + 4 + 5) / 3 = 4.67
```

Shop rating is calculated separately from Shop reviews.

```text
Shop A

Review 1 = 4
Review 2 = 5
Review 3 = 4

Average = 4.33
```

Product reviews should NOT directly modify the Shop rating.

Later, cached fields such as:

```text
rating
reviewCount
```

can be added to Shop/Product for faster frontend responses.

```text

        ↓
Step 2
Create reviewController.js
        ↓
Step 3
Create reviewRoutes.js
        ↓
Step 4
Register routes in server.js
        ↓
Step 5
Start backend
        ↓
Step 6
Test every endpoint in Postman
        ↓
Step 7
Fix backend/API issues
        ↓
Step 8
Connect React frontend
        ↓
Step 9
Build Review UI
        ↓
Step 10
Add rating summary/cache later
```

The important principle is:

```text
POSTMAN SUCCESS
       ↓
API READY
       ↓
FRONTEND INTEGRATION
```

The frontend should consume the API; it should not contain the database
business logic.
